# KORbuild

KORbuild is the development repository for the commercial V1 platform for team operations, employee evaluations, occurrences, bonuses and operational workflows.

## Environments

- `Nardacci/robustconstructions` — current client production application. Do not modify from this repository.
- `Nardacci/korbuild` — independent product development.
- Supabase `obratech-db-dev` — development database.

## V1 principle

One product, one codebase, configurable per company. Customer-specific customizations should be isolated and paid for rather than creating separate product versions.
